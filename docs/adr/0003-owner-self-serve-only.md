# The user is the owner, running the skill on their own business

The 2026-08-27 decision named "technical owners who install the skill" as the audience, and the first real runs (2026-08-27 to 28) tested that with the author acting as a consultant on six client businesses and on his own. The consultant runs produced six inventories nobody acted on, and the self run started by auditing the wrong business. On 2026-08-30 Hunter decided: the person in the chat owns the business, the accounts, and the runtime. There is no consultant or proxy mode. The interview asks the owner, the consent step asks the owner, and the roadmap speaks to the owner. Personal operations join the audit only when the owner adds them as a source category.

The skills are renamed to match the new shape: `workflow-audit` becomes `ops-audit`, `workflow-build` becomes `ops-foundation`. The old names keep working as redirects for a while.

Consequences: no "whose business" step, no proxy flag, no evidence label for a proxy's answers. A consultant who wants to run this on a client sits in the client's seat with the client's accounts, or does not run it.
