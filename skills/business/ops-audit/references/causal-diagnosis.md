# Causal diagnosis

For each observed sink, write the actual path: trigger, collection, judgment, action, destination, read-back, failure visibility, and existing coverage. Make separate cards when paths differ. A card states action, cost or unknown, coverage, diagnosis, proof, disclosed evidence, and intervention.

Choose in this order: remove; simplify; deterministic rule; leverage move; bounded agent automation. An agent receives a fixed task and output shape, cannot select the next step, and sits between deterministic collection and a gate. Name the approver for consequential actions. Mark absent proof as unknown, not likely.
